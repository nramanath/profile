## My Projects

Here are some of the projects I have worked on:

- **Travel SMS**: Developed a cloud based application to provide Places and Directions through SMS. Built using Twilio SMS, Google Maps and Google Places Services and hosted in Google App Engine.
- **CloudPi**: Developed a cloud using AWS EC2 and AWS SQS with in-house auto scaling implemented.
- **Stack Overflow Clone**: Developed Recommendation Engine (Content Based and Collaborative Filtering) using Stack Overflow dataset and built a full-fledged web application like Stack Overflow using Java Spring and Jersey Backend and Angular 2 Frontend.
- **Brain Driven Security**: Developed a Brain Driven Security android mobile application that authenticates with user’s brain signals using ML learning.
- **AI Pacman**: Developed an Artificially Intelligent Pacman in Python based on Adversarial Search and Hidden Markov models.
